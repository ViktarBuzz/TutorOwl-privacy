# Политика конфиденциальности TutorOwl

Дата вступления в силу: 15 октября 2026 года

TutorOwl помогает репетитору вести список клиентов, расписание занятий, посещаемость и расчёты. Приложение не содержит рекламы, аналитики и систем отслеживания.

## Какие данные обрабатываются

Пользователь может самостоятельно внести имена и контактные данные клиентов и их представителей, расписание, сведения о занятиях, отменах и заметках, ставки, счета, историю оплат, а также данные групп и их участников.

Эти данные хранятся локально на устройстве. Разработчик TutorOwl не получает и не хранит их на своих серверах.

## Разрешения устройства

- **Контакты** используются только по команде пользователя для заполнения имени и телефона выбранного контакта.
- **Календарь** используется только по команде пользователя для добавления занятий в календарь устройства.
- **Уведомления** используются для напоминаний о занятиях.
- **Интернет** используется для резервного копирования в Dropbox и открытия WhatsApp.

Приложение не считывает контакты или календарь в фоновом режиме.

## Dropbox

Если пользователь подключает Dropbox, TutorOwl загружает резервную копию рабочих данных в личную папку приложения в аккаунте Dropbox пользователя. После подключения копия автоматически обновляется при изменении данных. Она может содержать введённые пользователем имена, контакты, расписание, заметки, ставки, счета и историю оплат.

Dropbox используется как поставщик облачного хранения. Разработчик TutorOwl не получает эту копию. Пользователь может отключить Dropbox в настройках TutorOwl и удалить файл из Dropbox.

## WhatsApp

По команде пользователя TutorOwl открывает WhatsApp или веб-ссылку WhatsApp с подготовленным сообщением. Отправка выполняется только после действия пользователя.

## Хранение и удаление

Пользователь может изменить или удалить клиентов, занятия, группы и платежи. Полное удаление локальных данных выполняется очисткой данных приложения или удалением приложения. Копию в Dropbox пользователь удаляет отдельно.

## Дети

TutorOwl предназначен для работы репетитора, а не для самостоятельного использования детьми. Пользователь, вносящий сведения о несовершеннолетнем, отвечает за наличие законного основания и необходимых согласий.

## Безопасность

Приложение использует HTTPS и запрещает незашифрованный HTTP-трафик. Автоматическое системное резервное копирование базы клиентов и OAuth-токенов Android отключено.

## Контакты

По вопросам конфиденциальности: [tutorowlsupport@gmail.com](mailto:tutorowlsupport@gmail.com)

# TutorOwl Privacy Policy

Effective date: October 15, 2026

TutorOwl helps tutors manage clients, schedules, attendance, and billing. The app contains no advertising, analytics, or tracking SDKs.

Data entered by the user is stored locally on the device. The TutorOwl developer does not receive or store this data on developer-operated servers.

Contacts and calendar permissions are used only after an explicit user action. Notification permission is used for lesson reminders. Internet access is used for user-authorized Dropbox backups and opening WhatsApp.

When Dropbox is connected, TutorOwl uploads a backup to the app folder in the user's own Dropbox account and automatically updates it after data changes. The backup may contain names, contact details, schedules, notes, rates, invoices, and payment history entered by the user. Dropbox acts as the user's cloud storage provider; the TutorOwl developer does not receive the backup.

Users can delete local data by clearing app data or uninstalling TutorOwl. Dropbox copies must be removed separately by the user.

TutorOwl is intended for tutors, not for independent use by children. A user entering a minor's information is responsible for having a lawful basis and any required consent.

Privacy contact: [tutorowlsupport@gmail.com](mailto:tutorowlsupport@gmail.com)
